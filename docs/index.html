Tier table

The leader of each tier: its share of Sonnet 5.5's long-coding score, the Artificial Analysis Intelligence Index v5.0.1 with the Coding Agent Index v2.1 in brackets, its size (total parameters, with active parameters for mixture-of-experts models), and its download size on disk: a 4-bit build first, then the full-precision release in its native format (BF16, FP8 or FP4). Disk sizes are Hugging Face file sizes as listed by LLM Sizer, in decimal GB; "≈ … est." marks an estimate where no file size is listed. "Explain" opens the article's reasoning for that tier; "more" shows the other models in the tier. Model names link to their source. Data file: long-coding-tasks-2026-11-17.csv.

not scored means the Artificial Analysis Coding Agent Index does not cover that model (it only includes large models), not that the model scored zero. Those tiers rest on Terminal-Bench 4.0 and FrontierCode 2.0 alone.

The Intelligence Index is a general index across all of Artificial Analysis's evaluations, shown so every model is rated on one scale. It is not the basis of the tiers: it rates Nanbeige4.3-33B and Qwen3.8 27B almost equally, although Nanbeige is about twice as good on long coding tasks.
