How the tiers were defined

Every model is compared on long coding tasks: multi-step agent work in real repositories and terminals, where one task takes tens of minutes and hundreds of steps. The score used for tiers is the average of Terminal-Bench 4.0 and FrontierCode 2.0, divided by Sonnet 5.5's average. Both run on every model Artificial Analysis tests, including small open ones.

    The band edges are a judgement call, placed where the data has natural gaps (nothing open sits between 60% and 88%). The best model in a tier is the open-weights model with the highest long-coding score in that band. Where a model also has a Coding Agent Index score (which runs each model inside a real coding agent), it agrees with this ranking for the top open models.

    Scores were measured at full precision through APIs. A quantized local build will usually score somewhat lower.
